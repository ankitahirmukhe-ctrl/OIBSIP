# OIBSIP - Web Development Internship Projects

This repository contains the web development projects completed as part of my **Web Development Internship at Oasis Infobyte (OIBSIP)**.

The projects were developed using **HTML, CSS, and JavaScript** to practice frontend development, responsive design, user interaction, and website development.

## Projects

### 1. Café Sunshine - Landing Page

A responsive landing page created for a fictional café called **Café Sunshine**.

The website focuses on creating a simple, attractive and user-friendly café experience.

**Features:**
- Fixed navigation bar
- Hero section
- Café menu
- About section
- Contact section
- Responsive layout
- Custom images
- Clean and simple UI

**Technologies:**
- HTML5
- CSS3

---

### 2. Personal Portfolio

A personal portfolio website created to showcase my profile, skills, projects, certifications, interests, education and achievements.

**Features:**
- Personal introduction
- About Me section
- Skills and technologies
- Projects showcase
- Certifications
- Hackathons
- Education
- Areas of Interest
- Contact section
- Responsive design
- Smooth navigation

**Technologies:**
- HTML5
- CSS3
- JavaScript

---

### 3. Temperature Converter

A responsive temperature conversion tool that allows users to convert temperatures between **Celsius, Fahrenheit and Kelvin**.

**Features:**
- Celsius conversion
- Fahrenheit conversion
- Kelvin conversion
- Input validation
- Absolute zero validation
- Displays converted values
- Responsive design
- Simple and interactive interface

**Technologies:**
- HTML5
- CSS3
- JavaScript
